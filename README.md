# Arzon Market 🛍️

Zamonaviy va qulay e-tijorat (online marketplace) platformasi.

## 🚀 Texnologiyalar
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **React Router v7**

## ✨ Asosiy Imkoniyatlar
- ⚡ 1 kunda bepul yetkazib berish tizimi
- 📱 Telefon va planshetlar uchun to'liq moslashuvchan (responsive) dizayn
- 🔍 Jonli qidiruv va filtrlar (5000+ mahsulotlar)
- 🛒 Savat va buyurtmalarni boshqarish
- 🌐 Ikki tilli interfeys (O'zbekcha / Русский)
- 📍 Shaharlar va topshirish punktlari xaritasi
- 🛡️ Error Boundary va xatoliklarni himoyalash

## 💻 Mahalliy ishga tushirish
```bash
npm install
npm run dev
```
